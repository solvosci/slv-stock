Preserves Show Operations option in Picking Type, that could be forced
to ``true`` sometimes across ``res.config.settings``.

This is due to standard stock addon behavior when lot, warehouse and
location options are set together.

Known issues / Roadmap
======================

This addon covers a bug already fixed in stock ``addon``.

See:

-  https://github.com/odoo/odoo/commit/d54a58706225fdfc920a03064b750769d75d91e0
-  https://github.com/odoo/odoo/commit/6f7e9a93048155e403e6cc56d24595c281297124

This addon is intended to cover such bug when Odoo is placed in an
earlier version and is not updatable, and shouldn't be used elsewhere.
