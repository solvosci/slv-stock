Enables s/n secure reservation in moves, preventing undesired situations
when a s/n is manually assigned.

This is initially applied to outgoing stock pickings, but it can be also
implemented for e.g. MRP productions

Usage
=====

Once installed the addon,

* Only users that belong to S/N Manager groups are able to edit S/N move lines from pickings.
* When available, S/N (de)assignment becomes more strict and assisted.
* S/Ns used in a picking can be locked there for other documents.
