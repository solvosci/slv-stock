Adds a new report that prints product labels.
It displays the barcode and the lot or serial number, if it has.
It also generates an MH10 Datamatrix QR code that can be scanned to retrieve the displayed data.

This report can be printed from the products and their variants, the delivery note, and the inventory report.

Installation
============

To install this addon, the python dependency ``pylibdmtx`` is required, that requires an external OS library dependency, ``libdmtx``.
To install it, you can use the following commands:

- For a typical recent Ubuntu-based distro (like e.g. Ubuntu 24.04, or Mint 22.x) use ``sudo apt install libdmtx0t64``
This will work for latest Debian version (Trixie, 13) as well.

- However, if Debian Bookworm (12) is used instead, we should use ``apt install libdmtx-dev``.

Usage
=====

To print the report, click on "Print QR Label" from each view

PRODUCTS AND VARIANTS

The "Barcode" field must be filled in.
If you try to print from a product that has variants, an error will occur; in that case, you can only print from the variants.
If the product has multiple lots or serial numbers, a wizard will open, allowing you to choose which lot/serial number to print

DELIVERY NOTES

If the delivery note contains more than one line, a receipt will be printed for each line.
If the product has an assigned lot number or serial number, it will be printed with the assigned lot/serial number.
If a product has more than one assigned lot number or serial number, a receipt will be printed for each lot number or serial number.

INVENTORY REPORT
A receipt will be printed for each selected product, showing its assigned lot number or serial number, if it has.
